极验验证（本地辅助页，仅测试用）

这个页面只做一件事：让你在真实浏览器里过一次 B 站的极验。
极验必须在浏览器里过 —— 提交时要带一个由本地 JS 生成的轨迹/指纹参数，库伪造不出来， 所以这一步的责任在调用方（本页就是"调用方"的一种实现）。
过完验证后，点按钮复制 7 行内容，粘贴到 __RESULT__（覆盖整个文件），Java 侧会自动读取。
（最后一行是 ua=，即本页所在浏览器的真实 UA；Java 侧会用它作为出站 UA， 让"过验的浏览器"与"提交登录的请求"是同一副面孔 —— 你可以不管它，照抄即可。）
⚠ 请通过 Java 侧打印的那个 http://127.0.0.1:端口/… 地址打开本页 —— 直接双击文件用 file:// 打开的话，极验一定加载不出来（页面里会说明原因）。
